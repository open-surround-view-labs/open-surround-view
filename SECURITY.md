# Security and privacy

Do not open a public issue containing credentials, private camera URLs, device serial numbers, precise locations, or identifiable camera images.

The application can connect to cleartext HTTP streams because many embedded camera systems expose video only on a private local network. Use it only on a trusted network. Do not expose a camera stream to the public internet.

Until a private security contact is established, report only non-sensitive security concerns through GitHub issues. For sensitive reports, withhold exploit details and request a private reporting channel from the maintainers.
